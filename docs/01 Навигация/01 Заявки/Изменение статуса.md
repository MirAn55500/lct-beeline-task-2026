# Изменение статуса

Принятое изменение статуса или подтвержденных сроков выполнения заявки.

## Атрибуты

`+` - обязательно. `-` - допускается отсутствие либо действует условие из примечания. PK - первичный ключ, FK - ссылка, UK - уникальная комбинация. Вычисляемые поля не требуют отдельного хранения. Типы и дополнительные поля являются проектом реализации на основе принятой ER-схемы.

## Связи и правила

- История хранит отдельно время события и время получения. Позднее получение не означает более поздний факт.
- Начало и окончание - подтвержденные факты, а не значения расчетного расписания. Событие с уточнением факта может иметь одинаковые предыдущий и новый статусы.
- Для начального события предыдущий статус пуст. Фактическое окончание не раньше фактического начала.
- Завершение и отмену вручную фиксирует диспетчер по сообщению исполнителя. Для внешнего источника используется уникальная пара source + external_event_id. Обработка запоздавших внешних сообщений относится к дополнительной интеграции.
- Назначение при наличии указывает версию плана, по которой велось выполнение. Факты не копируются в новые версии плана.
