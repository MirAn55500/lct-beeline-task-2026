# Элемент снэпшота

Связь обработанной записи файла с заявкой либо инженером и выполненным действием.

## Атрибуты

`+` - обязательно. `-` - допускается отсутствие либо действует условие из примечания. PK - первичный ключ, FK - ссылка, UK - уникальная комбинация. Вычисляемые поля не требуют отдельного хранения. Типы и дополнительные поля являются проектом реализации на основе принятой ER-схемы.

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание |
|---|---|---|---|---|---|---|
| `id` | Идентификатор | Автоматически: уникальный ключ записи | Идентификатор | + | snapshot_item-001 | PK. Обязательность ключа принята в модели |
| `snapshot` | Снэпшот загрузки | Автоматически или пользователь: ссылка на связанную запись | Идентификатор | + | snapshot-001 | FK: [[Снэпшот загрузки]].snapshot_id |
| `action_type` | Действие загрузки | Автоматически или пользователь: ссылка на связанную запись | Идентификатор | + | dict-001 | FK: [[Словарное значение]].dict_id. Группа словаря: `import_action` |
| `request` | Заявка | Автоматически или пользователь: ссылка на связанную запись | Идентификатор | - | request-001 | FK: [[Заявка на работу]].request_id |
| `engineer` | Инженер | Автоматически или пользователь: ссылка на связанную запись | Идентификатор | - | engineer-001 | FK: [[Инженер]].engineer_id |
| `row_number` | Номер строки | При загрузке: исходный номер строки с учетом заголовка | Целое число | + | 4 |  |
| `source_row` | Исходная строка | При загрузке: JSON с точными заголовками и всеми значениями строки | Строка (форматированная) | + | {"Заявка":"74198","Район":"Кузьминки"} | Показан фрагмент примера. Сохраняется полная строка без нормализации |

## Связи и правила

- UK: снэпшот + номер строки. Для элемента заполнена ровно одна ссылка: заявка или инженер, в соответствии с типом загрузки.
- Служебные и пустые строки не создают элементы. Строка без изменений получает действие unchanged.
- Исходная строка сохраняется неизменяемо с точными заголовками и значениями. Состав колонок описан в заметках исходных территорий.
- Ссылка ведет на текущую сущность. Историческое содержимое входного файла берется из исходной строки, а воспроизводимость расчета обеспечивает снимок входов плана.
