# Навык инженера

Связь инженера с навыком и личным уровнем владения.

## Атрибуты

`+` - обязательно. `-` - допускается отсутствие либо действует условие из примечания. PK - первичный ключ, FK - ссылка, UK - уникальная комбинация. Вычисляемые поля не требуют отдельного хранения. Типы и дополнительные поля являются проектом реализации на основе принятой ER-схемы.

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание |
|---|---|---|---|---|---|---|
| `id` | Идентификатор | Автоматически: уникальный ключ записи | Идентификатор | + | engineer_skill-001 | PK. Обязательность ключа принята в модели |
| `engineer` | Инженер | Автоматически или пользователь: ссылка на связанную запись | Идентификатор | + | engineer-001 | FK: [[Инженер]].engineer_id |
| `skill` | Навык | Автоматически или пользователь: ссылка на связанную запись | Идентификатор | + | dict-001 | FK: [[Словарное значение]].dict_id. Группа словаря: `skill` |
| `qualification_level` | Квалификация по навыку | Пользователь или синтетический набор: уровень владения навыком | Строка | - | null | Шкала не согласована |

## Связи и правила

- UK: инженер + навык. Число навыков не ограничено тремя значениями текущего набора.
- Навык является обязательным допуском. Отсутствие навыка исключает назначение. Дополнительная квалификация необязательна для базового расчета, ее шкалу и влияние выбирает команда.
