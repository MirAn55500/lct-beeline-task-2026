# Снаряжение инженера

Вид снаряжения, доступный инженеру в начале указанного дня.

## Атрибуты

`+` - обязательно. `-` - допускается отсутствие либо действует условие из примечания. PK - первичный ключ, FK - ссылка, UK - уникальная комбинация. Вычисляемые поля не требуют отдельного хранения. Типы и дополнительные поля являются проектом реализации на основе принятой ER-схемы.

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание |
|---|---|---|---|---|---|---|
| `id` | Идентификатор | Автоматически: уникальный ключ записи | Идентификатор | + | engineer_item-001 | PK. Обязательность ключа принята в модели |
| `engineer` | Инженер | Автоматически или пользователь: ссылка на связанную запись | Идентификатор | + | engineer-001 | FK: [[Инженер]].engineer_id |
| `item` | Снаряжение | Автоматически или пользователь: ссылка на связанную запись | Идентификатор | + | dict-001 | FK: [[Словарное значение]].dict_id. Группа словаря: `equipment` |
| `equipment_date` | Дата комплекта | Пользователь: указывает дату выдачи в начале дня | Дата | + | 2026-08-17 |  |

## Связи и правила

- UK: инженер + дата + вид снаряжения. Повторная запись не увеличивает количество.
- Комплект выдается в офисе на день. Для дополнительного количественного учета команда задает стартовый запас, потребность и расход. При динамике требуется достаточный остаток, один список видов этого не доказывает.
- Для расчета используется комплект на дату плана. Выдача в другой день не означает наличие в выбранную дату.
- Эта таблица фиксирует доступные виды на дату. Количественная модель остатков остается отдельным решением команды в Плане изменений по ответам экспертов и не считается реализованной наличием ссылки item.
