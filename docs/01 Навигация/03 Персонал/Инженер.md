# Инженер

Один исполнитель заявок, включенный в бригаду.

## Атрибуты

`+` - обязательно. `-` - допускается отсутствие либо действует условие из примечания. PK - первичный ключ, FK - ссылка, UK - уникальная комбинация. Вычисляемые поля не требуют отдельного хранения. Типы и дополнительные поля являются проектом реализации на основе принятой ER-схемы.

## Связи и правила

- Регион и офис наследуются от бригады. Для удаленного города допускается условный домашний адрес старта в этом городе. При заполненном home_address используется он, иначе офис. Межрегиональные назначения запрещены.
- Поля начала и окончания у инженера заполняются парой либо оба остаются пустыми. Пустая пара означает наследование времени бригады. Дни недели наследуются от бригады.
- Для конкретной даты приоритет имеет Изменение графика инженера. При отсутствии изменения действует личная пара времени, затем график бригады. Удаление личных значений восстанавливает наследование.
- Навыки и квалификация хранятся в Навыках инженера, комплект на дату - в Снаряжении инженера. Вложенные копии в профиле не хранятся.
- Емкость дня вычисляется по действующим рабочим интервалам. Личная скорость не изменяет норматив работы.
- Порядок входа нужен базовому алгоритму. Данные профилей инженеров в исходных выгрузках не предоставлены.
- Оборудование выдается в офисе на день. Для домашнего старта комплект должен быть доступен к началу маршрута. Способ доставки комплекта не включается в модель без отдельного решения.
