# Бригада

Группа инженеров одного региона с общим офисом старта и основным рабочим графиком. Хранит рабочие интервалы сотрудников и продолжительность рабочего дня. В исходных выгрузках колонка «Бригада» обозначает отдельного инженера, а не эту сущность сервиса.

## Правила

- Каждый инженер принадлежит одной бригаде. Работу по заявке выполняет один инженер.
- Бригада закреплена за одним регионом. Ее районы относятся к этому региону. Назначения между регионами запрещены.
- Адрес офиса задается в бригаде. В предоставленном наборе у бригад одного региона одна точка старта. Инженеры начинают рабочий день из этого офиса.
- График задает рабочие интервалы сотрудников бригады. Интервалы внутри дня упорядочены, не пересекаются, начало раньше окончания. Продолжительность дня вычисляется по интервалам и не редактируется отдельно.
- Индивидуальные изменения дня задаются у инженера. Без изменения действует график бригады.
- Перерывы можно задать разрывами интервалов как дополнительную возможность. Базовый расчет не требует моделирования перерывов.
- Расчет распределяет заявки в пределах одного дня. Возврат в офис при каждом пересчете не предполагается.
- Активность бригады определяет область отбора сотрудников, доступность конкретного инженера хранится в его профиле.

## Нормативы работ

[[Нормативы работ]] устанавливают оптимальное время, которое инженер должен потратить на один вызов соответствующей категории: дорогу до клиента/ТКД, технические работы и оформление документов. Значения заданы по видам работ; отдельных значений для конкретных бригад в файле нет. См. также [[Вид работ]].
