# Бригада

Группа инженеров с общими районами работы и основным рабочим графиком. В этой модели бригада и подразделение обозначают одну сущность.

## Атрибуты

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| **Основные сведения** |  |  |  |  |  |  |  |
| `id` | ID | Автоматически: система создает ID при добавлении бригады | Идентификатор | + | brigade-001 | Уникальный ключ; обязательность ключа принята в проекте модели | PK: первичный ключ |
| `name` | Название | Пользователь: вводит название бригады | Строка | + | Бригада Восток | Непустое название |  |
| **Доступность** |  |  |  |  |  |  |  |
| `active` | Активно | Пользователь: включает или исключает бригаду из выбора для планирования | Логический | + | true | Определяет участие в выборе области планирования |  |
| **Рабочий график** |  |  |  |  |  |  |  |
| `schedule.timezone` | Часовой пояс графика | Пользователь: выбирает часовой пояс в карточке бригады | Строка (форматированная) | + | Europe/Moscow | Например: Europe/Moscow |  |

## Правила

- График задается явно для каждой бригады.
- Интервалы внутри дня упорядочены и не пересекаются. Начало раньше окончания.
- Перерывы задаются разрывами, например 09:00-13:00 и 14:00-18:00.
- Работы и перемещения укладываются в рабочие интервалы. Перенос работы или переезда через перерыв в текущей модели не предусмотрен.
- График описывает интервалы внутри календарного дня. Ночные смены требуют расширения.
- Бригада и подразделение - одна сущность. Ее районы и график служат исходными значениями для инженеров.
- Строгость территориальной привязки пока не определена: ограничение назначения или предпочтение при выборе инженера.
