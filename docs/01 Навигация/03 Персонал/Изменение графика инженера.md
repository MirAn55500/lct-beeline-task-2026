# Изменение графика инженера

Индивидуальный рабочий график на конкретную дату.

## Атрибуты

`+` - обязательно. `-` - допускается отсутствие либо действует условие из примечания. PK - первичный ключ, FK - ссылка, UK - уникальная комбинация. Вычисляемые поля не требуют отдельного хранения. Типы и дополнительные поля являются проектом реализации на основе принятой ER-схемы.

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание |
|---|---|---|---|---|---|---|
| `id` | Идентификатор | Автоматически: уникальный ключ записи | Идентификатор | + | schedule-001 | PK. Обязательность ключа принята в модели |
| `engineer` | Инженер | Автоматически или пользователь: ссылка на связанную запись | Идентификатор | + | engineer-001 | FK: [[Инженер]].engineer_id |
| `date` | Дата изменения | Пользователь: выбирает день | Дата | + | 2026-08-17 |  |
| `intervals` | Рабочие интервалы | Пользователь: задает интервалы на дату | Массив/Список | + | [{"start_work":"10:00","end_work":"17:00"}] | Каждый элемент содержит start_work и end_work в HH:MM. [] означает отсутствие |
| `reason` | Причина изменения | Пользователь: при необходимости поясняет изменение | Строка | - | Изменение смены |  |

## Связи и правила

- UK: инженер + дата. Запись целиком заменяет действующий график инженера на дату.
- Пустой список интервалов означает отсутствие. Удаление записи восстанавливает личный или унаследованный график.
- Интервалы не пересекаются, окончание позже начала. Часовой пояс берется через бригаду, регион и город присутствия.
