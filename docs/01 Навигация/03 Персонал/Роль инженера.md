# Роль инженера

Необязательный шаблон навыков для заполнения профиля инженера. Личная квалификация и оборудование на день хранятся у инженера.

## Атрибуты

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| **Основные сведения** |  |  |  |  |  |  |  |
| `id` | ID | Автоматически: уникальный ключ записи | Идентификатор | + | role-001 | Предложение состава поля и обязательности; обязательность ключа принята в проекте модели | PK: первичный ключ |
| `name` | Название | Название для выбора в карточках и отображения в списках | Строка | + | Инженер по подключению | Предложение состава поля и обязательности |  |
| `description` | Описание | Пояснение назначения и границ использования записи | Строка | - | Используется для подключения и настройки оборудования | Предложение состава поля и обязательности |  |
| **Навыки шаблона** |  |  |  |  |  |  |  |
| `skill_ids` | Навыки роли | Пользователь: выбирает исходный набор навыков для заполнения профиля | Массив/Список | + | ["connection"] | Число навыков не ограничено. Уровни задаются у инженера | Коды списка [[Навык]] |
| **Доступность** |  |  |  |  |  |  |  |
| `active` | Доступно для выбора | Пользователь: разрешает выбор записи в новых карточках | Логический | + | true | Предложение; отключение не удаляет исторические связи |  |

## Правила

- Роль задает шаблон профессиональных навыков. Права доступа к сервису описываются отдельно.
- Выбор роли помогает заполнить профиль. Дальнейшее изменение роли не перезаписывает навыки и квалификацию инженера автоматически.
- Транспорт не зависит от роли или навыков. Оборудование выдается на день и не наследуется из роли.
