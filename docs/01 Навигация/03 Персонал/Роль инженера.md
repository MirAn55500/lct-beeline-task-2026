# Роль инженера

Необязательный шаблон начального набора навыков при заполнении профиля. В принятую ER-модель отдельная таблица роли не включена.

Выбранные навыки сохраняются в [[Навык инженера]]. Шаблон не определяет личную квалификацию, транспорт, снаряжение на дату и права доступа. Изменение шаблона не меняет уже сохраненные навыки инженеров автоматически.
