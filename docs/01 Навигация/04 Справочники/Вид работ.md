# Вид работ

Вид работы с нормативом обслуживания и требованиями к снаряжению.

## Атрибуты

`+` - обязательно. `-` - допускается отсутствие либо действует условие из примечания. PK - первичный ключ, FK - ссылка, UK - уникальная комбинация. Вычисляемые поля не требуют отдельного хранения. Типы и дополнительные поля являются проектом реализации на основе принятой ER-схемы.

## Связи и правила

- Для подключения, дозаказа и локальной заявки норматив обслуживания без дороги составляет 70, 20 и 30 минут. Для аварии по ответу экспертов от 19.09.2026 применяется рабочее значение 100 минут.
- Аварийные 100 минут заменяют прежние 60 минут. Рабочая трактовка - 100 минут выполнения плюс отдельно рассчитанная дорога. Включение дороги в ответ экспертов не уточнено, см. Нормативы работ и Открытые вопросы.
- Сопоставление BK/HD с категориями норматива требует настройки. Оно не выводится из навыка: один навык допускает несколько нормативов.
- Требуемый навык определяется по BK через отдельный маппинг. Копии навыка в виде работ нет. Точное соответствие пары BK/HD активно не дублируется.
- Виды оборудования выбираются из группы equipment. Тип подключения сам по себе не задает оборудование.
