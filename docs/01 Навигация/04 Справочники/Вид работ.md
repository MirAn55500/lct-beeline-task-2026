# Вид работ

Категория работы с требуемым навыком, нормативной длительностью и, при необходимости, снаряжением. С ней сопоставляется пара «Категория заявки в источнике» и «Тип работ в источнике» из выгрузки.

## Правила

- При создании заявки длительность копируется из вида работ, а требуемый навык определяется по BK по таблице в [[Навык]]. При ручном создании используется BK выбранного вида работ.
- Длительность обслуживания не уменьшается по личной скорости или квалификации инженера. Уточнение норматива требует основания и не сдвигает окно.
- Изменение справочника не меняет уже созданные заявки и планы работы.
- [[Нормативы работ]] устанавливают оптимальное полное время инженера на один вызов для четырех категорий: дорога, технические работы и документы. Их соответствие категориям заявок и типам работ в источнике еще нужно определить. Соответствие BK требуемым навыкам зафиксировано в [[Навык]]. Название типа само по себе не подтверждает соответствие.
- Для длительности обслуживания берется сумма технических работ и документов: 70, 80, 20 или 30 минут после сопоставления категории. Дорожные 20 минут полного норматива не прибавляются к отдельно рассчитанному перемещению.

- Одна пара «Категория заявки в источнике» и «Тип работ в источнике» должна соответствовать одному виду работ до автоматического сопоставления нормативов. Для навыка достаточно BK; записи видов работ с одинаковым BK не могут задавать разные навыки.
- Снаряжение копируется в новую заявку как исходное требование. Изменение вида работ не меняет требования уже сохраненной заявки автоматически.

[Открыть схему в FigJam](https://www.figma.com/board/qUsan6379lRSFny5OXwIX4/?node-id=2013-1448).

Требование оборудования не выводится из типа подключения. Личная квалификация относится к навыку инженера, правило ее влияния на назначение остается открытым.
