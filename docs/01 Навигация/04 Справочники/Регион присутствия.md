# Регион присутствия

Территория загрузки заявок и работы бригад.

## Атрибуты

`+` - обязательно. `-` - допускается отсутствие либо действует условие из примечания. PK - первичный ключ, FK - ссылка, UK - уникальная комбинация. Вычисляемые поля не требуют отдельного хранения. Типы и дополнительные поля являются проектом реализации на основе принятой ER-схемы.

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание |
|---|---|---|---|---|---|---|
| `region_id` | Идентификатор | Автоматически: уникальный ключ записи | Идентификатор | + | region-001 | PK. Обязательность ключа принята в модели |
| `region_code` | Код региона | Пользователь: задает устойчивый код региона | Строка | + | east | UK: уникальный код. Сохраняет прежние значения key |
| `region_name` | Название региона | Пользователь: задает название региона | Строка | + | Восток |  |
| `city` | Город присутствия | Автоматически или пользователь: ссылка на связанную запись | Идентификатор | + | city-001 | FK: [[Город присутствия]].city_id |

## Связи и правила

- Один регион содержит районы и связан с городом присутствия. Заявки загружаются по одному региону за раз.
- Стабильные коды исходных регионов: east - Восток, southeast - Юго-восток, southcentral - Югоцентр.
- Часовой пояс получается через город присутствия. Офис и график принадлежат бригаде. Копии этих параметров в снэпшоте загрузки не хранятся.
