# Словарное значение

Общая запись одного справочного значения из определенной группы.

## Атрибуты

`+` - обязательно. `-` - допускается отсутствие либо действует условие из примечания. PK - первичный ключ, FK - ссылка, UK - уникальная комбинация. Вычисляемые поля не требуют отдельного хранения. Типы и дополнительные поля являются проектом реализации на основе принятой ER-схемы.

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание |
|---|---|---|---|---|---|---|
| `dict_id` | Идентификатор | Автоматически: уникальный ключ записи | Идентификатор | + | dict-001 | PK. Обязательность ключа принята в модели |
| `group` | Группа | При настройке: назначение справочного значения | Строка | + | skill |  |
| `code` | Код | При настройке: устойчивый код внутри группы | Строка | + | connection | UK вместе с group |
| `value` | Название | При настройке: название для пользователя | Строка | + | Работы на подключение и дозаказы |  |
| `description` | Описание | Пользователь: пояснение значения | Строка | - | Подключение и дополнительное оборудование |  |
| `active` | Доступно для выбора | Пользователь: разрешает выбор значения | Логический | + | true |  |

## Связи и правила

- UK: группа + код. value используется для отображения, code - для устойчивого сопоставления.
- Каждая ссылка на словарь проверяет группу. Например, в transport допустима только группа transport, в skill - только skill.
- Группы и начальные значения приведены в Словари модели. Названия из CSV хранятся точно в value и исходной строке.
- Отключение значения запрещает новый выбор, но не удаляет исторические связи. Вид работ хранится отдельно, поскольку задает норматив обслуживания.
