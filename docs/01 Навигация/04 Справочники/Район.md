# Район

Район внутри одного региона присутствия.

## Атрибуты

`+` - обязательно. `-` - допускается отсутствие либо действует условие из примечания. PK - первичный ключ, FK - ссылка, UK - уникальная комбинация. Вычисляемые поля не требуют отдельного хранения. Типы и дополнительные поля являются проектом реализации на основе принятой ER-схемы.

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание |
|---|---|---|---|---|---|---|
| `id` | Идентификатор | Автоматически: уникальный ключ записи | Идентификатор | + | area-001 | PK. Обязательность ключа принята в модели |
| `area` | Название | Название для выбора в карточках и отображения в списках | Строка | + | Кузьминки | Предложение состава поля и обязательности |
| `region` | Регион | Автоматически или пользователь: ссылка на связанную запись | Идентификатор | + | region-001 | FK: [[Регион присутствия]].region_id |
| `source_names` | Названия в выгрузках | Пользователь: сопоставляет значения колонки «Район» с территорией сервиса | Массив/Список | - | ["Кузьминки"] | Массив строк<br>не объединять город и район автоматически |
| `description` | Описание | Пояснение назначения и границ использования записи | Строка | - | Территория работы бригад и инженеров | Предложение состава поля и обязательности |
| `active` | Доступно для выбора | Пользователь: разрешает выбор записи в новых карточках | Логический | + | true | Предложение<br>отключение не удаляет исторические связи |

## Связи и правила

- Каждый район принадлежит одному региону. Адреса относятся к району.
- Сопоставление исходного названия выполняется внутри региона загрузки. Совпадение названий в разных регионах не объединяет районы.
- В шести предоставленных выгрузках пересечения названий районов между регионами не обнаружены. GPON Даниловский и Даниловский не объединяются автоматически.
