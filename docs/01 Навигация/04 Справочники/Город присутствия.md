# Город присутствия

Город операционного присутствия и общий часовой пояс связанных регионов.

## Атрибуты

`+` - обязательно. `-` - допускается отсутствие либо действует условие из примечания. PK - первичный ключ, FK - ссылка, UK - уникальная комбинация. Вычисляемые поля не требуют отдельного хранения. Типы и дополнительные поля являются проектом реализации на основе принятой ER-схемы.

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание |
|---|---|---|---|---|---|---|
| `city_id` | Идентификатор | Автоматически: уникальный ключ записи | Идентификатор | + | city-001 | PK. Обязательность ключа принята в модели |
| `city_name` | Название города | Пользователь: задает название города присутствия | Строка | + | Москва |  |
| `timezone` | Часовой пояс | Пользователь: задает часовой пояс загрузки и графиков | Строка (форматированная) | + | Europe/Moscow | Идентификатор IANA |

## Связи и правила

- Один город присутствия объединяет несколько регионов. Часовой пояс задается здесь и получается через регион при загрузке и планировании.
- Город присутствия не заменяет населенный пункт в адресе. Регион может обслуживать адреса Москвы, Домодедова, Каширы и Ступино.
- Для предоставленных наборов подтвержден Europe/Moscow. Привязка к городу присутствия настраивается явно, без подстановки города в исходные адреса.
