# Снаряжение

Значения группы `equipment` в [[Словарное значение|общем словаре]]. Для текущего сценария используются роутер (`router`) и приставка (`set_top_box`). Отдельной таблицы видов снаряжения нет.

Выдача инженеру на дату хранится в [[Снаряжение инженера]]. Требования заявки и вида работ содержат ссылки на значения этой группы. Тип подключения не определяет снаряжение. Количество и расход остаются в [[Открытые вопросы|открытых вопросах]].
