# Маппинг BK с навыком

Правило определения одного требуемого навыка по категории BK.

## Атрибуты

`+` - обязательно. `-` - допускается отсутствие либо действует условие из примечания. PK - первичный ключ, FK - ссылка, UK - уникальная комбинация. Вычисляемые поля не требуют отдельного хранения. Типы и дополнительные поля являются проектом реализации на основе принятой ER-схемы.

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание |
|---|---|---|---|---|---|---|
| `id` | Идентификатор | Автоматически: уникальный ключ записи | Идентификатор | + | mapping-001 | PK. Обязательность ключа принята в модели |
| `request_type_bk` | Категория BK | Автоматически или пользователь: ссылка на связанную запись | Идентификатор | + | dict-001 | FK: [[Словарное значение]].dict_id. Группа словаря: `request_type_bk` |
| `skill` | Требуемый навык | Автоматически или пользователь: ссылка на связанную запись | Идентификатор | + | dict-001 | FK: [[Словарное значение]].dict_id. Группа словаря: `skill` |

## Связи и правила

- UK: request_type_bk. Для одной категории BK существует одно действующее соответствие навыку.
- Подключение и Дозаказ требуют connection, Локальная заявка - local, Глобальная проблема - emergency.
- HD не меняет навык. Информация с BK Глобальная проблема требует emergency. Неизвестный BK уточняется до расчета.
- В исходном скриншоте request_type_vk приведено к request_type_bk в соответствии с названием категории.
