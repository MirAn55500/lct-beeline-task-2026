# Маршрут инженера

Дневное представление назначений одного инженера в выбранном плане. Отдельная таблица полного маршрута не требуется. Таблица [[Маршрут]] хранит входящий участок пути к одному назначению.

## Состав представления

| Поле представления | Значение |
|---|---|
| `plan` | [[План работы]].plan_id |
| `engineer` | [[Инженер]].engineer_id |
| `assignment_ids` | Успешные [[Назначение на заявку|назначения]], упорядоченные по position |
| `working_intervals` | Действующие интервалы из сохраненных входов плана |
| `capacity_minutes` | Сумма рабочих интервалов |
| `service_minutes` | Сумма длительности обслуживания назначений |
| `travel_minutes` | Сумма времени [[Маршрут|участков пути]] |
| `waiting_minutes` | Сумма ожидания в рабочих интервалах |
| `remaining_capacity_minutes` | Емкость минус обслуживание, перемещения и ожидание |
| `distance_km` | Сумма расстояний участков |
| `start_at` | Первое отправление |
| `end_at` | Окончание последнего обслуживания |
| `geometry` | Геометрии участков в порядке назначений |

## Правила

- Ключ представления: план + инженер. Порядок назначений однозначно определен позицией.
- Первоначальный маршрут начинается в офисе бригады либо из условного домашнего адреса инженера, возвращение не требуется. При пересчете допустима подтвержденная текущая позиция.
- Все работы относятся к региону инженера, путь и работа укладываются в рабочие интервалы. Свободные минуты сами по себе не гарантируют возможность вставить заявку.
- Старые назначения и геометрия не перезаписываются при создании нового плана. Показатели вычисляются по сохраненной версии.
- Представление открывается внутри плана по инженеру на карте и в расписании.
