# Маршрут инженера

Составная часть [[План работы|плана работы]] для одного инженера: упорядоченный список назначений, время перемещений, расписание и расстояние. Маршрут сохраняется вместе с результатами плана. Его ID нужен для связей и сравнения планов.

## Правила

- Уникальна пара план + инженер. Для незадействованного сотрудника маршрут не создается.
- Возврат в стартовую точку после последней заявки отсутствует.
- Свободные минуты не гарантируют возможность вставить заявку: также нужны подходящие окна и время в пути.
- Геометрия собирается из incoming_geometry назначений. Порядок assignment_ids совпадает с position.

## Отображение в плане

Переход: план работы → инженер → маршрут. Маршрут открывается на карте и в расписании выбранного плана; из него доступны назначения. Самостоятельного реестра маршрутов вне плана нет.
