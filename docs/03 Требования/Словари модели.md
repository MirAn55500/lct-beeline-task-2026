# Словари модели

Физическая таблица: [[Словарное значение]]. Внешние ссылки используют dict_id, устойчивые коды хранятся в code. Приведенные коды служебных статусов и событий являются проектом реализации. Завершение и отмену фиксирует диспетчер. Внешняя интеграция относится к дополнительному сценарию.

| Группа | Назначение | Значения / источник |
|---|---|---|
| `skill` | Навыки | local, connection, emergency |
| `transport` | Способы передвижения | car, walking, bicycle, public_transport |
| `equipment` | Снаряжение | router, set_top_box |
| `priority` | Приоритет заявки | emergency, connection, repair_or_addon |
| `upload_type` | Тип загрузки | request, engineer |
| `file_type` | Формат файла | csv, xlsx, json |
| `upload_status` | Состояние загрузки | processing, completed, failed |
| `import_action` | Действие загрузки | created, updated, unchanged |
| `execution_status` | Статус выполнения | unknown, pending, en_route, in_progress, completed, cancelled |
| `assignment_status` | Результат назначения | assigned, unassigned |
| `plan_status` | Статус плана | draft, pending_approval, active, archived, cancelled |
| `calculation_status` | Состояние расчета | not_started, calculating, ready, needs_data, failed |
| `algorithm` | Алгоритм | baseline, optimized |
| `unassigned_reason` | Причина неназначения | no_skill, no_region, no_work_time, no_transport, no_equipment, time_conflict, not_found |
| `request_type_bk` | Категория BK | Значения: Локальная заявка, Подключение, Дозаказ, Глобальная проблема |
| `request_type_hd` | Тип работ HD | 18 исходных значений из Маппинга типов заявок |
| `replan_event_type` | Тип события пересчета | request_added, request_changed, status_changed, engineer_changed |

Код BK/HD создается устойчиво при настройке словаря, исходная подпись хранится без изменения в value. Нельзя использовать значение одной группы в поле другой.

Состав навыков и правила BK приведены в [[Навык]], соответствие хранится в [[Маппинг BK с навыком]]. Состав типов исходного файла не меняется.
