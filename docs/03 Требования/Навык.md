# Навык

Допуск инженера к определенному типу заявок. В ответах экспертов квалификация означает прежде всего право выполнять работу: без нужного навыка назначение запрещено. Дополнительный уровень владения навыком можно моделировать отдельно.

## Категория заявки (BK) → требуемый навык

Названия трех навыков взяты из [ТЗ, раздел 2.4.1](../../../Техническое%20задание.pdf#page=4), страница 3 документа (4-я страница PDF). Коды - технические обозначения модели. Соответствие категориям BK зафиксировано как правило проекта от 18.09.2026; в ТЗ готовой таблицы BK → навык нет.

| Категория заявки в Beekeeper (`Тип заявки BK`) | Требуемый навык из ТЗ | Код |
|---|---|---|
| Локальная заявка | Локальные работы | `local` |
| Подключение | Работы на подключение и дозаказы | `connection` |
| Дозаказ | Работы на подключение и дозаказы | `connection` |
| Глобальная проблема | Аварийные работы | `emergency` |

Требуемый навык заявки определяется только по BK. HD не участвует в выборе навыка; наблюдаемые пары приведены в [[Маппинг типов заявок]]. У каждой заявки ровно один требуемый навык. При неизвестном или пустом BK сначала уточняется категория.

В текущем наборе используются три навыка из ТЗ. По ответам сессии число навыков инженера не ограничено; список может быть расширен при появлении новых категорий работ.

## Использование

- [[Навык инженера]] хранит связи инженера с навыками и личную квалификацию. [[Роль инженера]] может служить шаблоном начального заполнения.
- [[Вид работ]] хранит ссылку на категорию BK. Навык определяется через [[Маппинг BK с навыком]]. В [[Заявка на работу|заявке]] навык вычисляется по ее BK; значения для одной категории должны совпадать. Наличие навыка у инженера проверяется при назначении.
- Модель навыков и транспорт можно задать синтетически. Для обязательного расчета достаточно наличия или отсутствия навыка. Дополнительные компетенции и уровни команда вводит по необходимости; они не блокируют базовый расчет.
- Навыки независимы от способа передвижения. Наличие навыка не разрешает нарушать действующее время визита.

## Поля модели

- `Навык инженера.skill` ссылается на [[Словарное значение]] группы skill.
- `Навык инженера.qualification_level` задает необязательный личный уровень.
- `Маппинг BK с навыком.request_type_bk` и `skill` определяют правило допуска.
- `Заявка на работу.skill` вычисляется по BK. Расчет сохраняет использованный навык в снимке входов плана.
