# Навык

Тип заявок, которые может выполнять инженер. Квалификация - уровень владения конкретным навыком, а не синоним навыка.

## Категория заявки (BK) → требуемый навык

Названия трех навыков взяты из [ТЗ, раздел 2.4.1](../../../Техническое%20задание.pdf#page=4), страница 3 документа (4-я страница PDF). Коды - технические обозначения модели. Соответствие категориям BK зафиксировано как правило проекта от 18.09.2026; в ТЗ готовой таблицы BK → навык нет.

| Категория заявки в источнике (`Тип заявки BK`) | Требуемый навык из ТЗ | Код |
|---|---|---|
| Локальная заявка | Локальные работы | `local` |
| Подключение | Работы на подключение и дозаказы | `connection` |
| Дозаказ | Работы на подключение и дозаказы | `connection` |
| Глобальная проблема | Аварийные работы | `emergency` |

Требуемый навык заявки определяется только по BK. HD не участвует в выборе навыка; наблюдаемые пары приведены в [[Маппинг типов заявок]]. У каждой заявки ровно один требуемый навык. При неизвестном или пустом BK сначала уточняется категория.

В текущем наборе используются три навыка из ТЗ. По ответам сессии число навыков инженера не ограничено; список может быть расширен при появлении новых категорий работ.

## Использование

- [[Инженер]] хранит список навыков и квалификацию по каждому из них. [[Роль инженера]] может служить шаблоном начального заполнения.
- [[Вид работ]] хранит требуемый навык, вычисленный по своей категории BK. В [[Заявка на работу|заявке]] навык вычисляется по ее BK; значения для одной категории должны совпадать. Наличие навыка у инженера проверяется при назначении.
- Квалификацию нужно добавить синтетически: исходных уровней в выгрузках нет. Шкала и правило влияния уровня на распределение пока не определены, см. [[Открытые вопросы]].
- Навыки независимы от способа передвижения. Квалификация не используется как коэффициент личной скорости и не разрешает начало работ раньше окна.

## Поля модели

- `Инженер.skills[].skill_id` и `Инженер.skills[].qualification_level` - навык и личный уровень.
- `Инженер.skill_ids` - вычисляемый список кодов для проверки наличия навыка.
- `Роль инженера.skill_ids` - шаблон навыков.
- `Вид работ.required_skill_id`, `Заявка на работу.required_skill_id`, `Назначение на работу.checked_skill_id` - требование и проверенный навык.
