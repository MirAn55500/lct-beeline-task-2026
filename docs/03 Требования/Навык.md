# Навык

Тип заявок, которые может выполнять инженер. Квалификация - уровень владения конкретным навыком, а не синоним навыка.

## Значения

Исходные коды модели приведены ниже. Соответствие типам BK/HD уточняется при подготовке набора. Число навыков инженера не ограничивается тремя; при необходимости список кодов расширяется без введения обязательного редактора в интерфейсе.

| Код | Название |
|---|---|
| `local` | Локальные работы |
| `connection` | Работы на подключение и дозаказы |
| `emergency` | Аварийные работы |

## Использование

- [[Инженер]] хранит список навыков и квалификацию по каждому из них. [[Роль инженера]] может служить шаблоном начального заполнения.
- [[Вид работ]] задает требуемый навык, который сохраняется в [[Заявка на работу|заявке]]. Наличие навыка проверяется при назначении.
- Квалификацию нужно добавить синтетически: исходных уровней в выгрузках нет. Шкала и правило влияния уровня на распределение пока не определены, см. [[Открытые вопросы]].
- Навыки независимы от способа передвижения. Квалификация не используется как коэффициент личной скорости и не разрешает начало работ раньше окна.

## Поля модели

- `Инженер.skills[].skill_id` и `Инженер.skills[].qualification_level` - навык и личный уровень.
- `Инженер.skill_ids` - вычисляемый список кодов для проверки наличия навыка.
- `Роль инженера.skill_ids` - шаблон навыков.
- `Вид работ.required_skill_id`, `Заявка на работу.required_skill_id`, `Назначение на работу.checked_skill_id` - требование и проверенный навык.
