# Способ передвижения

Фиксированный список способов перемещения. Значение определяет расчет времени в пути и совместимость инженера с требованием заявки. Управление составом списка в интерфейсе не предусмотрено.

## Значения

| Код | Название | Комментарий |
|---|---|---|
| `car` | Автомобиль | |
| `walking` | Пешком | |
| `bicycle` | Велосипед | |
| `public_transport` | Общественный транспорт | |

## Использование

- У [[Инженер|инженера]] выбирается один `transport_mode`. Значение принадлежит инженеру и не наследуется от роли.
- В [[Заявка на работу|заявке]] необязательное поле `required_transport_mode` задает требование. Если оно заполнено, способ передвижения инженера должен совпадать с ним.
- [[Маршрут инженера]] сохраняет способ передвижения из входных данных плана.
- Соответствие кодов профилям маршрутного API задается в технической конфигурации приложения. См. [[Правила модели#Техническая конфигурация]]. При недоступности профиля система сообщает о проблеме, а не подменяет способ передвижения.

## Подготовка набора

Способ передвижения можно генерировать синтетически. Пешие инженеры и пользователи общественного транспорта должны преобладать. Точные доли фиксируются в параметрах генерации. Транспорт не выводится из навыков или квалификации. При прочих равных более быстрое перемещение предпочтительнее меньшего расстояния.

Поддержка общественного транспорта проверяется у маршрутного сервиса отдельно: возможность геокодировать адрес не подтверждает наличие транспортного профиля.
