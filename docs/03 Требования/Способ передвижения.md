# Способ передвижения

Фиксированный список способов перемещения. Значение определяет расчет времени в пути и совместимость инженера с требованием заявки. Управление составом списка в интерфейсе не предусмотрено.

## Значения

| Код | Название | Комментарий |
|---|---|---|
| `car` | Автомобиль | |
| `walking` | Пешком | |
| `bicycle` | Велосипед | |
| `public_transport` | Общественный транспорт | |

## Использование

- У [[Инженер|инженера]] выбирается один `transport`. Значение принадлежит инженеру и не наследуется от роли.
- В [[Заявка на работу|заявке]] необязательное поле `transport` задает требование. Если оно заполнено, способ передвижения инженера должен совпадать с ним.
- [[Назначение на заявку]] сохраняет использованный способ передвижения, [[Маршрут]] получает его по связи с назначением.
- Метод оценки для каждого способа передвижения задается в технической конфигурации. Для общественного транспорта допустимы усредненная скорость или время между точками. Параметры и происхождение оценки сохраняются в снимке плана.

## Подготовка набора

Способ передвижения можно генерировать синтетически. Пешие инженеры и пользователи общественного транспорта должны преобладать. Точные доли фиксируются в параметрах генерации. Транспорт не выводится из навыков или квалификации. При прочих равных более быстрое перемещение предпочтительнее меньшего расстояния.

Реальные маршруты общественного транспорта не обязательны. Комбинированное перемещение и реалистичные маршруты без автомобиля - дополнительная возможность. При выборе API наличие транспортного профиля проверяется отдельно от геокодирования.

Физическое хранение: [[Словарное значение]], группа transport. Поля transport содержат dict_id, а не текстовый код.
