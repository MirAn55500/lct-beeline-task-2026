# Югоцентр

Ниже приведены атрибуты листов «Югоцентр - синтетика» и «Югоцентр - контроль» в исходном порядке. Примеры взяты из указанной ячейки соответствующего листа.

**Адрес офиса:** г.Москва проезд Симферопольский, д.7 (ячейка `B62`, метка `Адрес офиса` в `A62`). Это служебная строка, а не заявка. Адрес хранится в `metadata.office_address` и используется как адрес офиса бригады региона, откуда инженеры начинают день.
