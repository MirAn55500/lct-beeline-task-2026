# Маппинг типов заявок

## Тип заявки в HelpDesk (HD) → категория заявки в источнике (BK)

BK обозначает Beekeeper, HD - HelpDesk. Таблица связывает классификаторы одной заявки в двух системах; правило определения навыка только по BK сохраняется.

Фактические пары из шести восстановленных CSV: «Восток», «Юго-восток», «Югоцентр», синтетические данные и контрольное распределение. Проверены 410 строк заявок: 205 синтетических и 205 контрольных. Это две версии наборов, а не 410 уникальных заявок. Найдены 18 значений HD и 20 пар HD/BK. Служебные строки офисов исключены.

## Правило применения

- HD содержит тип заявки в HelpDesk. Требуемый навык определяется только по BK, по таблице в [[Навык]].
- «Конвергенция абонента» и «Заказ подключения/Дозаказ оборудования» встречаются с двумя категориями BK: «Подключение» и «Дозаказ». HD не позволяет выбрать одну из них. Обе категории требуют одного навыка - «Работы на подключение и дозаказы».
- Используется BK из строки выгрузки. HD не подменяет и не переопределяет эту категорию. Если BK отсутствует или неизвестен, категорию нужно уточнить до расчета; навык по умолчанию не назначается.
- Эта таблица описывает наблюдаемые пары предоставленного набора. Для нового значения HD при известном BK навык по-прежнему определяется по BK.
- Для «Информация» в выгрузках указан BK «Глобальная проблема», поэтому применяется навык «Аварийные работы». Классификация не выводится из звучания HD.

## Источники

Восстановленные CSV находятся в `Наборы данных/Датасеты (восстановленные)` рядом с базой. Число заявок в каждом синтетическом и каждом контрольном файле: Восток - 66, Юго-восток - 83, Югоцентр - 56. Исходные заголовки и значения сохранены без переименования.
