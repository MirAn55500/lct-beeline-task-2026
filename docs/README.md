# База знаний - ЛЦТ 2026

Начните с [навигации сервиса](01%20Навигация/01%20Навигация.md).

Склонируйте репозиторий целиком и откройте его папку `docs` как хранилище Obsidian. Все заметки, вложения и настройки Obsidian находятся внутри `docs`. На этом компьютере плагин Obsidian Git автоматически находит `.git` в родительской папке. Поля `Base path` и `Custom .git directory path` оставьте пустыми.

## Порядок ведения

- Одна сущность или правило описывается в одном месте, в папке своей сферы.
- Название, тип, проект и теги хранятся в YAML. `section` ведет к разделу карты, `related` содержит короткий список связанных заметок. Назначение и обязательность связей описаны в таблицах атрибутов.
- При переименовании обновляйте ссылки, при изменении состава сервиса - карту. Поле `updated` обновляется вручную.
- Для синхронизации используйте `Git: Pull` перед работой и `Git: Commit-and-sync` после проверки изменений.

Плагины: [Folder Notes](https://github.com/LostPaul/obsidian-folder-notes), [PlantUML](https://github.com/joethei/obsidian-plantuml), [Advanced Tables](https://github.com/tgrosinger/advanced-tables-obsidian), [Git](https://github.com/Vinzent03/obsidian-git). PlantUML получает SVG от публичного сервера; передаются только названия узлов карт. В плагине сохранено исправление внутренних ссылок.

Исходные XLSX, CSV, PDF и резервные копии находятся вне репозитория. Относительные ссылки на исходные файлы рассчитаны на текущую структуру локальных папок.
