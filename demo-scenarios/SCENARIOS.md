# Сценарии с нуля (стенд)

Регион: **Юго-восток**. Дата: **28.09.2026** (сегодня).

В продукте **нет кнопки «Импорт инженеров»** — только ручное добавление и экспорт. Для стенда:

1. файл `00-engineers-southeast.csv` — список для ручного ввода **или**
2. seed: из `backend/` выполнить `python -m modules.personnel.seed_southeast` (создаст бригаду + 12 инженеров).

Нужны backend и frontend на стенде.

---

## 0. Персонал (с нуля)

**Файл:** `00-engineers-southeast.csv` (или `.json`).

1. Меню → **Персонал**. Создайте бригаду Юго-восток, если её нет (офис `г. Москва, ул Бирюлёвская, д 1с1`, смена 09:00–22:00).
2. Жёлтая кнопка **Инженеры** (или ▼ → **Импорт csv / json**).
3. Выберите бригаду → перетащите `00-engineers-southeast.csv` → **Загрузить**.
4. Чтобы добавить одного: в панели ссылка **Нажмите здесь** или ▼ → **Добавить**.

**Ожидание:** тост «Добавлено N инженеров»; в таблице 12 человек; без короны в карточке бригады.

Альтернатива без UI: `cd backend && python -m modules.personnel.seed_southeast`.

---

## 1. Первичная загрузка заявок

**Файл:** `02-southeast-mini.csv` (быстро) или `01-southeast-full.csv` (83 заявки).

1. Шапка: регион **Юго-восток**, дата **28 сентября 2026**.
2. **Заявки** → файл → уровень **Свободный** → **Загрузить**.

**Ожидание:** «Считаем план» → **План № N**, маршруты на карте/ганте.

---

## 2. Сравнение с базовым

1. **План № N** → **Новый план**.
2. **Свободный** + **Эффективное** → **Обновить план**.

**Ожидание:** диалог сравнения (заявки → инженеры → время → км). При **Равномерном** диалога нет.

---

## 3. Отмена заявки

1. **Карта** → инженер → остановка → **Отменить заявку**.
2. **Понятно** → снова **Новый план** (Свободный / Эффективное).

**Ожидание:** заявка не возвращается после пересчёта.

`05-with-cancelled-row.csv` — при импорте строка «Отменена» пропускается.

---

## 4. Недоступен с 12:00

1. Инженер → **Недоступен с…** → **12:00** → **Пересчитать остаток дня**.

**Ожидание:** окно «Что изменилось», смена обрезана, новая версия плана.

---

## 5. Догрузка (Фикс)

**Файл:** `03-new-tickets-fix.csv`.

1. **Заявки** → файл → **Фикс** → **Загрузить**.

**Ожидание:** id `901001`–`901003` появились; старые назначения по возможности целы.

---

## 6. Авария

**Файл:** `04-emergency-free.csv` → **Свободный** → **Загрузить**.

**Ожидание:** авария в плане, маршруты могут сильно измениться.

---

## 7–9. Карта / Гант / Экспорт

- Drag неназначенной в маршрут → остаётся после обновления.
- **Гант** ↔ **Карта** — одни назначения.
- **Заявки** ▼ → **Экспорт csv/json** → тост «скачан».

---

## 10. Другой регион

**Файлы:** `00-engineers-southcentral.csv` + `06-southcentral-mini.csv`.

1. Заведите инженеров Югоцентра (руками или по аналогии с seed).
2. Регион **Югоцентр**, дата **28.09.2026**, загрузите мини-заявки (**Свободный**).
