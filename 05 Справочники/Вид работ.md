# Вид работ

Категория работы с требуемым навыком, нормативной длительностью и, при необходимости, снаряжением. С ней сопоставляются типы BK и HD из выгрузок.

Состав полей и обязательность - проект модели. Примеры отдельных полей условные и не образуют одну запись. `+` - обязательно; `-` - необязательно или требуется при условии из примечания.

|---|---|---|---|---|---|---|---|
| `id` | ID | Автоматически: система создает ID при добавлении вида работ | Идентификатор | + | work-type-001 | Уникальный ключ; обязательность ключа принята в проекте модели |  |

## Правила

- При создании заявки навык и длительность копируются в заявку.
- Длительность заявки может быть уточнена отдельно от норматива.
- Изменение справочника не меняет уже созданные заявки и версии планов.
- Соответствие типов BK/HD навыкам и нормативные минуты еще нужно определить. Название типа само по себе не подтверждает длительность.

- Одна пара исходных типов BK/HD должна соответствовать одному виду работ до автоматического сопоставления.
- Снаряжение копируется в новую заявку как исходное требование. Изменение вида работ не меняет требования уже сохраненной заявки автоматически.
