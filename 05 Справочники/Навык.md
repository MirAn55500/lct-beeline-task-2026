# Навык

Квалификация для выполнения работы. В ТЗ предусмотрены локальные работы, работы на подключение и дозаказы, аварийные работы.

Состав полей и обязательность - проект модели. Примеры отдельных полей условные и не образуют одну запись. `+` - обязательно; `-` - необязательно или требуется при условии из примечания.

## Идентификация

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| `id` | ID | Автоматически: система создает код при начальном заполнении трех навыков по ТЗ | Идентификатор | + | connection | local, connection, emergency; обязательность ключа принята в проекте модели |  |

## Описание квалификации

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| `name` | Название | Автоматически: система заполняет три названия навыков из ТЗ при первом запуске | Строка | + | Работы на подключение и дозаказы | Локальные работы / Работы на подключение и дозаказы / Аварийные работы |  |
| `description` | Описание | Пользователь: уточняет описание навыка в справочнике | Строка | - | Используется для подключения и настройки оборудования | Пояснение границ квалификации |  |

## Правила

- Каждой заявке соответствует один требуемый навык.
- Сотрудник подходит, если требуемый навык входит в его список.
- Состав из трех навыков взят из ТЗ. Уровни квалификации в MVP отсутствуют.
