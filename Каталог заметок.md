# Каталог заметок

[[README|Главная]] · [[Работа с базой знаний]]

Списки обновляются в Obsidian через Dataview по свойствам заметок. Для чтения на GitHub используйте [[README|главную страницу]].

## Основные материалы

```dataview
LIST
WHERE project = "ЛЦТ 2026" AND type != "entity" AND type != "section" AND type != "index" AND type != "guide" AND !startswith(file.path, "Шаблоны/")
SORT file.name ASC
```

## Разделы сервиса

```dataview
LIST
FROM "Разделы"
WHERE type = "section"
SORT file.name ASC
```

## Сущности по разделам

```dataview
LIST rows.file.link
FROM "Сущности"
WHERE type = "entity"
GROUP BY section
SORT key ASC
```
