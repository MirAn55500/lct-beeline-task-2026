# Назначение на работу

Результат распределения заявки в версии плана: инженер, время и место работы либо причина неназначения.

Состав полей и обязательность - проект модели. Примеры отдельных полей условные и не образуют одну запись. `+` - обязательно; `-` - необязательно или требуется при условии из примечания.

## Идентификация и контекст

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| `id` | ID | Автоматически: система создает ID результата распределения заявки | Идентификатор | + | assignment-001 | Уникальный ключ; обязательность ключа принята в проекте модели |  |
| `version_id` | Версия | Автоматически: ID выполняемого расчета из Версии плана | Идентификатор | + | version-001 | Версия результата; обязательность ключа принята в проекте модели |  |
| `request_id` | Заявка | Автоматически: ID обрабатываемой заявки из снимка входных данных | Идентификатор | + | request-001 | Одна заявка; обязательность ключа принята в проекте модели |  |

## Правила

- Пара version_id + request_id уникальна. При assigned заполнены сотрудник, маршрут, порядок и плановые сроки. При unassigned эти поля пусты.
- Позиции назначений в маршруте уникальны и непрерывны. Начало работы не раньше прибытия. Следующий путь не раньше окончания предыдущей работы.
- Начало работы входит в окно заявки, вся работа и перемещения укладываются в рабочие интервалы сотрудника.
- no_skill: нет квалифицированного сотрудника. no_work_time: у подходящих по навыку сотрудников нет рабочих интервалов.
- time_conflict означает конфликт времени в проверенных вариантах. not_found означает, что алгоритм не нашел назначение, но глобальная невозможность не доказана.
- Объяснение не утверждает сравнение с альтернативой, если она не рассчитывалась.
- Критерии locked для работ в пути и в процессе еще не согласованы. Выполненные работы сохраняются в истории и не назначаются повторно.
- no_transport означает отсутствие инженера с требуемым транспортом, no_equipment - отсутствие требуемого снаряжения. При нескольких препятствиях объяснение перечисляет выявленные ограничения.
