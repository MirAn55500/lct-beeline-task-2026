# Маршрут инженера

Упорядоченный список назначенных работ с временем перемещений, расписанием и расстоянием.

Состав полей и обязательность - проект модели. Примеры отдельных полей условные и не образуют одну запись. `+` - обязательно; `-` - необязательно или требуется при условии из примечания.

| `version_id` | Версия | Автоматически: ID выполняемого расчета из Версии плана | Идентификатор | + | version-001 | Одна версия; обязательность ключа принята в проекте модели |  |
| `engineer_id` | Сотрудник | Автоматически: ID сотрудника, которому алгоритм назначил заявки | Идентификатор | + | engineer-001 | Один исполнитель; обязательность ключа принята в проекте модели |  |

## Правила

- Уникальна пара версия + сотрудник. Для незадействованного сотрудника маршрут не создается.
- Возврат в стартовую точку после последней заявки отсутствует.
- Свободные минуты не гарантируют возможность вставить заявку: также нужны подходящие окна и время в пути.
- Геометрия собирается из incoming_geometry назначений. Порядок assignment_ids совпадает с position.
