# Снаряжение

Вид инструмента или оборудования, доступность которого учитывается у инженера и в требованиях к работе.

Состав полей и обязательность - проект модели. Примеры отдельных полей условные и не образуют одну запись. `+` - обязательно; `-` - необязательно или требуется при условии из примечания.

## Основные сведения

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| `id` | ID | Автоматически: уникальный ключ записи | Идентификатор | + | equipment-001 | Предложение состава поля и обязательности; обязательность ключа принята в проекте модели |  |
| `name` | Название | Название для выбора в карточках и отображения в списках | Строка | + | Оптический тестер | Предложение состава поля и обязательности |  |
| `description` | Описание | Пояснение назначения и границ использования записи | Строка | - | Инструмент для проверки оптической линии | Предложение состава поля и обязательности |  |

## Классификация

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| `code` | Код вида снаряжения | Пользователь: задает устойчивый код вида инструмента или оборудования | Строка | + | optical_tester | Предложение; без серийных номеров и учета складских остатков |  |

## Доступность

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| `active` | Доступно для выбора | Пользователь: разрешает выбор записи в новых карточках | Логический | + | true | Предложение; отключение не удаляет исторические связи |  |

## Правила

- Учитывается наличие вида снаряжения. Учет количества, выдачи и совместного использования одного физического экземпляра в эту модель не включен.
- Требование работы сравнивается с итоговым списком снаряжения инженера. В ТЗ это дополнительная возможность.
