# Способ передвижения

Один из четырех способов перемещения инженера. Определяет профиль расчета маршрута и совместимость с требованием заявки.

Состав полей и обязательность - проект модели. Примеры отдельных полей условные и не образуют одну запись. `+` - обязательно; `-` - необязательно или требуется при условии из примечания.

## Основные сведения

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| `id` | ID | Автоматически: код одного из четырех способов передвижения | Идентификатор | + | car | car, walking, bicycle, public_transport; код используется в transport_mode; обязательность ключа принята в проекте модели |  |
| `name` | Название | Название для выбора в карточках и отображения в списках | Строка | + | Автомобиль | Предложение состава поля и обязательности |  |
| `description` | Описание | Пояснение назначения и границ использования записи | Строка | - | Перемещение на автомобиле | Предложение состава поля и обязательности |  |

## Расчет маршрутов

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| `routing_profile` | Профиль маршрутного API | Настройка соответствия способа передвижения профилю выбранного API | Строка | - | driving (условный пример) | Условие: До расчета. Предложение; точное значение зависит от поставщика API |  |

## Правила

- Четыре значения по ТЗ: автомобиль, пешком, велосипед, общественный транспорт. Инженер использует одно значение; в заявке требование необязательно.
- Значение routing_profile определяют после выбора API. Нельзя незаметно заменять недоступный профиль другим способом передвижения.
