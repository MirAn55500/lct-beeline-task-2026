# Район работы

Территория выполнения работ. Используется для привязки заявок и определения районов работы бригад и инженеров.

Состав полей и обязательность - проект модели. Примеры отдельных полей условные и не образуют одну запись. `+` - обязательно; `-` - необязательно или требуется при условии из примечания.

## Основные сведения

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| `id` | ID | Автоматически: уникальный ключ записи | Идентификатор | + | district-001 | Предложение состава поля и обязательности; обязательность ключа принята в проекте модели |  |
| `name` | Название | Название для выбора в карточках и отображения в списках | Строка | + | Кузьминки | Предложение состава поля и обязательности |  |
| `description` | Описание | Пояснение назначения и границ использования записи | Строка | - | Территория работы бригад и инженеров | Предложение состава поля и обязательности |  |

## Обозначения источника

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| `source_names` | Названия в выгрузках | Пользователь: сопоставляет значения колонки «Район» с территорией сервиса | Массив/Список | - | ["Кузьминки"] | Массив строк; не объединять город и район автоматически |  |

## Доступность

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| `active` | Доступно для выбора | Пользователь: разрешает выбор записи в новых карточках | Логический | + | true | Предложение; отключение не удаляет исторические связи |  |

## Правила

- Значения «Домодедово» и «GPON Даниловский» из источника требуют явного сопоставления. Пустая привязка заявки означает, что район еще не определен.
- Принадлежность к району хранится в заявке; районы бригады наследуются инженерами с индивидуальными исключениями. Строгость ограничения требует уточнения.
