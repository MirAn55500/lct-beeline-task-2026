# Роль инженера

Типовой набор навыков и снаряжения, назначаемый инженеру. Служит основой его возможностей при распределении работ.

Состав полей и обязательность - проект модели. Примеры отдельных полей условные и не образуют одну запись. `+` - обязательно; `-` - необязательно или требуется при условии из примечания.

## Основные сведения

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| `id` | ID | Автоматически: уникальный ключ записи | Идентификатор | + | role-001 | Предложение состава поля и обязательности; обязательность ключа принята в проекте модели |  |
| `name` | Название | Название для выбора в карточках и отображения в списках | Строка | + | Инженер по подключению | Предложение состава поля и обязательности |  |
| `description` | Описание | Пояснение назначения и границ использования записи | Строка | - | Используется для подключения и настройки оборудования | Предложение состава поля и обязательности |  |

## Навыки и снаряжение

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| `skill_ids` | Навыки роли | Пользователь: выбирает базовый набор навыков инженеров этой роли | Массив/Список | + | ["connection"] | Массив ID навыков; итоговый набор инженера должен удовлетворять ТЗ |  |
| `equipment_ids` | Снаряжение роли | Пользователь: выбирает стандартно доступное снаряжение | Массив/Список | + | ["equipment-001"] | Массив ID; пустой список означает отсутствие стандартного снаряжения |  |

## Доступность

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| `active` | Доступно для выбора | Пользователь: разрешает выбор записи в новых карточках | Логический | + | true | Предложение; отключение не удаляет исторические связи |  |

## Правила

- Роль определяет профессиональные возможности, а не права доступа к сервису. Транспорт в роль не входит.
- При изменении роли обновляются наследуемые значения инженеров; индивидуальные исключения имеют приоритет. Снаряжение здесь означает типовую доступность, а не учет выдачи инвентарного объекта.
