# План работы

План распределения заявок на выбранную дату и состав инженеров.

Состав полей и обязательность - проект модели. Примеры отдельных полей условные и не образуют одну запись. `+` - обязательно; `-` - необязательно или требуется при условии из примечания.

## Идентификация

| Наименование параметра | Название | Описание параметра | Тип данных | Обязательность | Пример заполнения | Примечание | Комментарий |
|---|---|---|---|---|---|---|---|
| `id` | ID | Автоматически: система создает ID при создании плана | Идентификатор | + | plan-001 | Уникальный ключ; обязательность ключа принята в проекте модели |  |
| `name` | Название | Пользователь: вводит название при создании плана | Строка | + | Восток, 17 августа | Название рабочего плана |  |
| `created_at` | Создан | Автоматически: система фиксирует время создания плана | Дата и время | + | 2026-08-17T09:00:00+03:00 | Время создания |  |

## Правила

- Каждый расчет сохраняет отдельную версию.
- Метрики, назначения и маршруты принадлежат версии, а не изменяемому контейнеру плана.
- Выбор текущей версии определяет то, что показывает Обзор дня.

## Отображение плана

Обзор диспетчера фильтруется по дате и бригаде. Для действующего плана показываются версия, время последнего расчета, назначенные заявки / все заявки плана, отдельно неназначенные срочные, задействованные / доступные инженеры. До выбора источника статусов показатели остаются плановыми.

Действия: рассчитать, открыть расписание и карту, сравнить с базовым вариантом, пересчитать и выбрать действующую версию.
