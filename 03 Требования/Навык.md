# Навык

Фиксированный список квалификаций для распределения работ. Пользователь выбирает значения в роли инженера, индивидуальных корректировках и требованиях вида работ. Управление составом списка в интерфейсе не предусмотрено.

## Значения

| Код | Название | Комментарий |
|---|---|---|
| `local` | Локальные работы | |
| `connection` | Работы на подключение и дозаказы | |
| `emergency` | Аварийные работы | |

## Использование

- [[Роль инженера]] задает базовый набор навыков, [[Инженер]] может индивидуально его корректировать. Итоговый набор содержит от одного до трех различных значений.
- [[Вид работ]] задает один требуемый навык, который копируется в [[Заявка на работу|заявку]]. Инженер подходит, если этот навык входит в его итоговый набор.
- Поля `skill_ids`, `required_skill_id`, `checked_skill_id` и `skill_overrides[].skill_id` хранят коды из этого списка. Существующие имена полей сохранены; отдельные записи навыков не создаются.
- Уровни квалификации в текущую модель не включены.
