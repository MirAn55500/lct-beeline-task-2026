# Навык

[[Навигация сервиса]] · [[Настройки]]

Квалификация, требуемая для заявки и доступная сотруднику.

## Атрибуты

| Поле | Название | Тип | Обязательность | Источник | Комментарий |
|---|---|---|---|---|---|
| **Идентификация** |  |  |  |  |  |
| `id` | ID | Строка | Да | Автоматически: система создает код при начальном заполнении трех навыков по ТЗ | local, connection, emergency |
| **Описание квалификации** |  |  |  |  |  |
| `name` | Название | Строка | Да | Автоматически: система заполняет три названия навыков из ТЗ при первом запуске | Локальные работы / Работы на подключение и дозаказы / Аварийные работы |
| `description` | Описание | Строка | Нет | Пользователь: уточняет описание навыка в справочнике | Пояснение границ квалификации |

## Правила

- Каждой заявке соответствует один требуемый навык.
- Сотрудник подходит, если требуемый навык входит в его список.
- Состав из трех навыков взят из ТЗ. Уровни квалификации в MVP отсутствуют.
