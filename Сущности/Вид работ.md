# Вид работ

[[Навигация сервиса]] · [[Настройки]]

Классификация заявок с требуемым навыком и нормативной длительностью.

## Атрибуты

| Поле | Название | Тип | Обязательность | Источник | Комментарий |
|---|---|---|---|---|---|
| **Идентификация** |  |  |  |  |  |
| `id` | ID | Строка | Да | Автоматически: система создает ID при добавлении вида работ | Уникальный ключ |
| `name` | Название | Строка | Да | Пользователь: задает название в справочнике видов работ | Понятное название работы |
| **Требования и нормативы** |  |  |  |  |  |
| `required_skill_id` | Требуемый навык | ID навыка | Да | Пользователь: выбирает требуемый навык для вида работ | Один навык |
| `default_duration_minutes` | Нормативная длительность | Целое, минуты | Да | Пользователь: вводит норматив времени; в CSV длительности работ нет | Больше нуля |
| **Сопоставление с источником** |  |  |  |  |  |
| `source_type_bk` | Тип BK | Строка | Нет | Пользователь: выбирает точное значение колонки CSV `Тип заявки BK` и связывает его с видом работ | Точное значение исходного файла |
| `source_type_hd` | Тип HD | Строка | Нет | Пользователь: выбирает точное значение колонки CSV `Тип заявки HD` для той же пары соответствия | Уточнение типа исходного файла |
| **Доступность** |  |  |  |  |  |
| `active` | Доступен для новых заявок | Логический | Да | Пользователь: включает вид работ для новых заявок | Исторические заявки сохраняют значения |

## Правила

- При создании заявки навык и длительность копируются в заявку.
- Длительность заявки может быть уточнена отдельно от норматива.
- Изменение справочника не меняет уже созданные заявки и версии планов.
- Соответствие типов BK/HD навыкам и нормативные минуты еще нужно определить. Название типа само по себе не подтверждает длительность.

- Одна пара исходных типов BK/HD должна соответствовать одному виду работ до автоматического сопоставления.
