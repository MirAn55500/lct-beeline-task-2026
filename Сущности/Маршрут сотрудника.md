# Маршрут сотрудника

[[Навигация сервиса]] · [[Планирование]]

Упорядоченные посещения одного сотрудника в версии плана.

## Атрибуты

| Поле | Название | Тип | Обязательность | Источник | Комментарий |
|---|---|---|---|---|---|
| **Идентификация и связи** |  |  |  |  |  |
| `id` | ID | Строка | Да | Автоматически: система создает ID маршрута при расчете | Уникальный ключ |
| `version_id` | Версия | ID версии | Да | Автоматически: ID выполняемого расчета из Версии плана | Одна версия |
| `employee_id` | Сотрудник | ID сотрудника | Да | Автоматически: ID сотрудника, которому алгоритм назначил заявки | Один исполнитель |
| **Старт и способ передвижения** |  |  |  |  |  |
| `start_latitude` | Широта старта | Число | Да | Автоматически: копируется `Сотрудник.start_latitude` из снимка; источник положения при пересчете начатого маршрута еще не выбран | От -90 до 90 |
| `start_longitude` | Долгота старта | Число | Да | Автоматически: копируется `Сотрудник.start_longitude` из снимка; источник положения при пересчете начатого маршрута еще не выбран | От -180 до 180 |
| `transport_mode` | Транспорт | Перечисление | Да | Автоматически: копируется `Сотрудник.transport_mode` из снимка входных данных | Профиль для API |
| **Состав и сроки маршрута** |  |  |  |  |  |
| `assignment_ids` | Заявки в маршруте | Упорядоченный список ID | Да | Автоматически: алгоритм упорядочивает ID назначений по порядку выполнения | ID назначений со статусом assigned, не менее одного |
| `start_at` | Время старта | Дата и время | Да | Автоматически: `incoming_departure_at` первого назначения в маршруте | Внутри рабочего времени |
| `end_at` | Окончание последней работы | Дата и время | Да | Автоматически: `service_end_at` последнего назначения в маршруте | Внутри рабочего времени |
| **Рабочее время и емкость** |  |  |  |  |  |
| `working_intervals` | Рабочие интервалы | Список объектов | Да | Автоматически: копируется `Сотрудник.effective_work_intervals` для даты плана | start_at, end_at: дата и время |
| `capacity_minutes` | Емкость дня | Целое, минуты | Расчет | Автоматически: сумма длительностей `working_intervals` в минутах | Сумма интервалов |
| **Занятость и свободное время** |  |  |  |  |  |
| `service_minutes` | Время работ | Целое, минуты | Расчет | Автоматически: сумма длительностей работ по назначениям маршрута | Сумма длительностей работ |
| `travel_minutes` | Время в пути | Число, минуты | Расчет | Автоматически: сумма `Назначение.incoming_travel_minutes`, полученных из маршрутного API | Включает первый участок |
| `waiting_minutes` | Ожидание в рабочее время | Число, минуты | Расчет | Автоматически: сумма `Назначение.waiting_minutes` | Ожидание окна, исключая перерывы |
| `remaining_capacity_minutes` | Свободное рабочее время | Число, минуты | Расчет | Автоматически: `capacity_minutes - service_minutes - travel_minutes - waiting_minutes` | Емкость минус работы, путь и ожидание |
| **Расстояние и объяснение** |  |  |  |  |  |
| `distance_km` | Расстояние | Число, км | Расчет | Автоматически: сумма `Назначение.incoming_distance_km`, полученных из маршрутного API | Сумма входящих участков посещений |
| `explanation` | Объяснение маршрута | Строка | Да | Автоматически: система формирует текст по ограничениям и критериям, повлиявшим на расчет маршрута | Какие ограничения и критерии повлияли |

## Правила

- Уникальна пара версия + сотрудник. Для незадействованного сотрудника маршрут не создается.
- Возврат в стартовую точку после последней заявки отсутствует.
- Свободные минуты не гарантируют возможность вставить заявку: также нужны подходящие окна и время в пути.
- Геометрия собирается из incoming_geometry назначений. Порядок assignment_ids совпадает с position.
