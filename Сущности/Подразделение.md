# Подразделение

[[Навигация сервиса]] · [[Сотрудники]]

Узел оргструктуры, объединяющий сотрудников и задающий основной рабочий график.

## Атрибуты

| Поле | Название | Тип | Обязательность | Источник | Комментарий |
|---|---|---|---|---|---|
| **Идентификация** |  |  |  |  |  |
| `id` | ID | Строка | Да | Автоматически: система создает ID при добавлении подразделения | Уникальный ключ |
| `name` | Название | Строка | Да | Пользователь: вводит название в оргструктуре | Непустое название |
| **Оргструктура и руководство** |  |  |  |  |  |
| `parent_id` | Родительское подразделение | ID подразделения | Нет | Пользователь: выбирает родительское подразделение в оргструктуре | Пусто для корня |
| `manager_id` | Руководитель | ID сотрудника | Нет | Пользователь: выбирает руководителя из сотрудников | Ссылка на сотрудника |
| **Рабочее время и доступность** |  |  |  |  |  |
| `active` | Активно | Логический | Да | Пользователь: включает или исключает подразделение из выбора для планирования | Определяет участие в выборе области планирования |
| **Основной рабочий график** |  |  |  |  |  |
| `schedule.timezone` | Часовой пояс графика | Строка IANA | Да | Пользователь: выбирает часовой пояс в карточке подразделения | Например: Europe/Moscow |
| `schedule.days` | Расписание недели | Список объектов | Да | Пользователь: задает рабочие интервалы на каждый день недели | Ровно 7 элементов |
| `schedule.days[].weekday` | День недели | Целое | Да | Пользователь: выбирает день в редакторе расписания | 1 - понедельник, 7 - воскресенье |
| `schedule.days[].intervals` | Интервалы дня | Список объектов | Да | Пользователь: задает интервалы работы выбранного дня | Пустой список означает выходной |
| `schedule.days[].intervals[].start_time` | Начало интервала | Время HH:MM | Да | Пользователь: вводит время начала работы |  |
| `schedule.days[].intervals[].end_time` | Конец интервала | Время HH:MM | Да | Пользователь: вводит время окончания работы |  |

## Правила

- Иерархия не содержит циклов. График задается явно для каждого подразделения.
- Интервалы внутри дня упорядочены и не пересекаются. Начало раньше окончания.
- Перерывы задаются разрывами, например 09:00-13:00 и 14:00-18:00.
- Работы и перемещения укладываются в рабочие интервалы. Перенос работы или переезда через перерыв в текущей модели не предусмотрен.
- График описывает интервалы внутри календарного дня. Ночные смены требуют расширения.
