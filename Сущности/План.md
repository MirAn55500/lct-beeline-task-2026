# План

[[Навигация сервиса]] · [[Планирование]]

Контейнер планирования на одну дату и выбранную группу сотрудников.

## Атрибуты

| Поле | Название | Тип | Обязательность | Источник | Комментарий |
|---|---|---|---|---|---|
| **Идентификация** |  |  |  |  |  |
| `id` | ID | Строка | Да | Автоматически: система создает ID при создании плана | Уникальный ключ |
| `name` | Название | Строка | Да | Пользователь: вводит название при создании плана | Название рабочего плана |
| `created_at` | Создан | Дата и время | Да | Автоматически: система фиксирует время создания плана | Время создания |
| **Дата и область планирования** |  |  |  |  |  |
| `date` | Дата | Дата | Да | Пользователь: выбирает день планирования | Планируемый день |
| `timezone` | Часовой пояс | Строка IANA | Да | Автоматически: копируется `Настройки.timezone`, заданный пользователем | Единый пояс отображения |
| `department_ids` | Подразделения | Список ID | Да | Пользователь: выбирает подразделения для расчета | Область отбора сотрудников |
| **Действующий результат** |  |  |  |  |  |
| `current_version_id` | Текущая версия | ID версии | Нет | Пользователь: выбирает готовую версию действующим планом | Пусто до первого принятого расчета |

## Правила

- Каждый расчет сохраняет отдельную версию.
- Метрики, назначения и маршруты принадлежат версии, а не изменяемому контейнеру плана.
- Выбор текущей версии определяет то, что показывает Обзор дня.
