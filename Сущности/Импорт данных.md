# Импорт данных

[[Навигация сервиса]] · [[Заявки]]

Одна загрузка файла с проверкой строк и результатом обработки.

## Атрибуты

| Поле | Название | Тип | Обязательность | Источник | Комментарий |
|---|---|---|---|---|---|
| **Идентификация и источник** |  |  |  |  |  |
| `id` | ID | Строка | Да | При импорте: система создает ID загрузки при выборе файла | Уникальный ключ |
| `source_key` | Код источника | Строка | Да | Пользователь: выбирает код набора перед импортом; синтетические и контрольные наборы разделяются | Разделяет внешние ключи |
| **Файл и формат** |  |  |  |  |  |
| `file_name` | Имя файла | Строка | Да | При импорте: система считывает имя выбранного пользователем файла | Имя исходного файла |
| `format` | Формат | Перечисление | Да | При импорте: система определяет формат загружаемого файла | csv, json |
| `encoding` | Кодировка | Строка | Для CSV | При импорте: система определяет кодировку CSV | UTF-8, допускается BOM |
| `delimiter` | Разделитель | Строка | Для CSV | При импорте: система определяет разделитель колонок CSV | Для предоставленных файлов точка с запятой |
| **Время и состояние загрузки** |  |  |  |  |  |
| `imported_at` | Время загрузки | Дата и время | Да | При импорте: система фиксирует время начала загрузки | Начало обработки |
| `status` | Статус | Перечисление | Да | При импорте: система обновляет состояние по результатам чтения и проверки файла | checking, completed, completed_with_errors, failed |
| **Результаты обработки** |  |  |  |  |  |
| `rows_total` | Строк прочитано | Целое | Расчет | При импорте: система считает все записи файла после заголовка | Все строки после заголовка |
| `created_count` | Создано | Целое | Расчет | При импорте: система считает успешно созданные заявки | Успешно созданные записи |
| `updated_count` | Обновлено | Целое | Расчет | При импорте: система считает заявки, обновленные по паре код источника + внешний ID | Успешно обновленные записи |
| `skipped_count` | Пропущено служебных строк | Целое | Расчет | При импорте: система считает пустые записи и служебную строку адреса офиса | Пустые строки и строка офиса |
| **Ошибки строк** |  |  |  |  |  |
| `errors` | Ошибки строк | Список объектов | Да | При импорте: система собирает ошибки чтения и проверки строк | Пустой список при отсутствии ошибок |
| `errors[].row_number` | Номер строки | Целое | Да | При импорте: номер ошибочной записи в файле с учетом заголовка | Номер записи с учетом заголовка |
| `errors[].field` | Поле | Строка | Нет | При импорте: название поля, на котором проверка обнаружила ошибку | Ключ ошибочного поля |
| `errors[].reason` | Причина | Строка | Да | При импорте: текст причины, сформированный проверкой строки | Понятный текст |
| **Метаданные файла** |  |  |  |  |  |
| `metadata.office_address` | Адрес офиса | Строка | Нет | Из выгрузки: вторая колонка служебной строки с меткой `Адрес Офиса` или `Адрес офиса` | Кандидат для старта сотрудников |
| **Параметры, заданные перед импортом** |  |  |  |  |  |
| `timezone` | Часовой пояс времени в файле | Строка IANA | Да | Пользователь: выбирает часовой пояс перед импортом | В колонках Начало и Окончание часовой пояс отсутствует |

## Правила

- Строка Адрес Офиса / Адрес офиса извлекается в метаданные. Пустые строки пропускаются.
- Ошибочные заявки не передаются оптимизатору. Они отображаются как ошибки импорта, отдельно от неназначенных заявок.
- Поле Начало/Окончание из CSV предлагается трактовать как границы окна. Значение требует подтверждения владельца данных.
- Бригада из контрольного CSV является исходным назначением, а не полным профилем сотрудника.
- Нормативы работ, навыки, приоритеты и профили сотрудников нужно дополнить до планирования.
- Сопоставление колонок и справочников описано в заметке Исходные данные.
