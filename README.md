# База знаний - ЛЦТ 2026

Материалы по сервису планирования рабочих маршрутов для инженеров: потребности пользователей, навигация, проект модели и описание исходных выгрузок.

Откройте эту папку как хранилище Obsidian. Начните с [навигации сервиса](Навигация%20сервиса.md). Порядок ведения заметок и работы с Git описан в [инструкции](Работа%20с%20базой%20знаний.md).

В Obsidian доступен [каталог по свойствам](Каталог%20заметок.md). Ниже приведены обычные ссылки для чтения на GitHub.

## Границы комплекта

В репозитории находятся заметки, вложения, шаблоны и общие настройки Obsidian. В заметках сохранены ссылки на CSV в соседней папке `Обезличивание` и на соседний PDF с ТЗ. Эти файлы находятся вне базы и в репозиторий не включены. Подробнее - в [инструкции](Работа%20с%20базой%20знаний.md).

Навигация описывает 14 сущностей, а проект атрибутивной модели содержит 10 отдельных заметок. Описания требуют согласования между собой; очистка базы не меняет принятые бизнес-решения.
